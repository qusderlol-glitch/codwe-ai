Как установить

Три шага. Установщик сам всё скачает и объяснит каждый пункт простыми словами.

  1. Скачайте и распакуйтеНажмите «Скачать для Windows», распакуйте архив в простую папку, например C:\CodweAI (без русских букв и пробелов).
  2. Запустите установщикДважды щёлкните Install Codwe AI.bat и не закрывайте чёрное окно, пока идёт установка.
  3. Следуйте окну-мастеруЕсли не уверены, нажимайте «Далее»: мастер сам выберет подходящее. Потом на рабочем столе появится ярлык Codwe AI.

Для входа понадобятся код подключения и пароль доступа. Их выдаёт тот, кто дал вам программу.

Частые вопросы

Windows пишет «Интеллектуальное управление приложениями заблокировало файл»

Это защита Windows 11 (Smart App Control). Она блокирует файлы из интернета, у которых нет платной цифровой подписи разработчика. У Codwe AI такой подписи пока нет. Это не вирус: исходный код открыт, его можно проверить на GitHub. Если Smart App Control у вас включён в строгом режиме, Windows не даст запустить установщик. Выбор за вами: либо подождать версию с подписью, либо самостоятельно изменить этот параметр Windows (Параметры → Конфиденциальность и защита → Безопасность Windows → Управление приложениями и браузером). Учтите, что включить его обратно можно только переустановкой Windows.

Windows показывает «Защитник Windows SmartScreen предотвратил запуск»

Нажмите «Подробнее», затем «Выполнить в любом случае». Причина та же: у программы пока нет платной подписи.

Мои фото и запросы кто-нибудь видит?

Нет. Они хранятся только на вашем компьютере. В облаке лежат только почта, ранг и статус блокировки. В интернет уходит лишь то, что вы сами запустили: поиск в Codwecode и скачивание моделей.

Почему есть блокировка некоторых запросов?

Сексуальный контент с несовершеннолетними блокируется всегда. Откровенный 18+ контент и жестокие сцены по умолчанию блокируются с объяснением причины; режим может менять администрация. Если запрос заблокирован, программа покажет, на каком слове сработала защита и что поправить.

Пропал интернет посреди установки

Ничего не потеряно. Запустите Install Codwe AI.bat снова: докачка продолжится с того же места.

Не приходит письмо с кодом

Проверьте папку «Спам», подождите минуту и нажмите «Отправить код ещё раз». Если не помогло, напишите тому, кто дал вам программу.
